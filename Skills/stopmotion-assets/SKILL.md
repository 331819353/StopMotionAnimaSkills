# 定格素材与动作套图

## 先确定整画面或分层模式

先读 [阶段母版与整画面替换](../stopmotion-production/references/full-frame-workflow.md)。用户指定不拼图时，每个动作输出完整镜头画面；三视图只约束角色形态，场景／阶段母版约束布局、几何和状态，前帧用于接续检查。先比较参考策略，不能默认多参考或前帧长链更稳。

整画面在同一完整图中解决角色、道具、遮挡和环境关系；输出完整画面，不裁角色回到分层拼装。以下透明素材、pivot、互斥层等要求只适用于已选择的分层模式，整画面使用全画布基准。

## 角色的生产粒度

每个动作形态生成完整角色，结构以当前母版为准，表情随整姿态生成。不输出角色的身体、附肢、操作部位或表情组件用于拼接；不能为节省生图改回分件角色。完整生成减少拼接风险，仍需检查身份、尺度和连续性。

复杂交互在生成图中解决接触、支撑和遮挡。整画面模式替换完整画面；分层模式输出完整角色与交互组合，并独立复用环境。科普模型可分件，无角色镜头无需套用角色粒度。

阅读 [定格语言](../stopmotion-production/references/stopmotion-language.md)、[资产交接规范](../stopmotion-production/references/project-contract.md)，生产时按需读 [素材规格与提示词](references/asset-spec.md)。检查当前镜头需求与已有资产，先复用再新增。

## 前期小样与正式生产

分镜前只做必要母版、材质与替换可行性小样。测试代表角度或接触动作，确认身份、几何、状态与材质连续；分层另检查透明边缘与支点，整画面另检查静态区域漂移。不要在动态分镜未稳定时生成完整动作库。

正式阶段从锁定分镜反推需求：整画面列阶段母版和完整目标姿态帧；分层列背景、角色、道具和接触组合。机制状态与精确标注按镜头安排。静止输出帧复用已有状态，只有可见变化才需新图；完整画面不默认能拆成可用透明素材。

## 参考体系

区分两种参考：

- 资产母版：身份、结构、比例、表面设计、材质、角度、色板、光向、画布、支点；为后续派生提供真实图像。
- 镜头／阶段母版：构图、站位、机位、几何、灯光与事件时间状态；先验收再作为整画面派生基准。角色三视图不承担场景几何或状态定义。

需要动作替换的角色优先锁定可辨认轮廓和支撑方式。换角度必须保持结构与材质一致，不靠同一提示词或种子声称一致。

## 生成与整理

生成前读取 [连续性与物理规范](../stopmotion-production/references/continuity-and-physics.md) 和 [提示词分层与绑定](../stopmotion-production/references/prompt-contract.md)，从当前项目展开尺度、机位、进入状态、允许变化、操作资源、支撑与动作阶段。关键输入缺失或冲突时先修设计；不得沿用上个 demo 的参数或把项目台账 ID 当作工具已知信息。

1. 发现当前真实可用的生图／编辑工具，遵守该工具及其适用 skill。优先从选定母版编辑派生，附真实参考；工具不支持所需参考方式就先测试并说明限制，不假设能力。
2. 按当前模式生成完整镜头画面或完整角色／交互组合；整画面保持固定画布和场景地标，目标状态从已验收阶段母版派生，不能把失败帧晋升母版。分层时，保留共同画布、机位、单位尺度和支撑关系；同母版派生并在相应支撑基准翻看检查。每个可合成文件只放一个完整姿态，不做肢体装配。多姿态参考板只能作为索引，须分出每个完整姿态再清理对齐，不是切成身体部件。
3. 需要 cutout 时明确请求透明背景；检查文件实际 alpha，白色或棋盘格背景不等于透明。编辑、去背、裁切后重新计算支点，避免轮廓损失和角色缩放跳变。
4. 统一尺寸、方向、接触坐标、光向、纹理和地面；透明图层中不包含意外背景。接触阴影单列，或随组合素材明确管理，不能重复叠阴影。
5. 保存真实文件、版本、精确实际提示词及参数来源、母版引用、姿态语义和检查结果，填资产索引；新规范不覆写历史调用记录。

## 专项素材

整画面模式保持完整布景并检查未参与动作的区域，不强制拆层。分层模式按需要拆远景、中景、地面、前景遮挡与干净底图；固定景复用，含角色的整幅图不能当作可自由摆放背景。不能只把一张背景切成几条就声称获得正确视差。

交互动作按实际机制与依赖设计整画面状态或完整角色姿态；多角色交互在同一生成图内解决。分层模式的组合标记所含实体，并与独立层互斥交接；状态、所属关系和接触位置跨交接继承。真实遮挡不靠拆下的角色部件覆盖补救。小样按当前项目风险选择，见素材规格，不固定测试动作清单。

科普部件按 claim_id 校对结构和状态映射。精确标签、箭头、公式、数字和图表用确定性绘图／排版生成后参与摆放；不让普通生图承担精确文本或测量证据。示意模型与真实观测来源分别登记。

## 质量与重试

整画面先翻看全幅地标、未授权变化与背景闪烁，再检查角色／道具；分层则在实际支撑／接触基准上叠看与翻看整姿态，并在真实镜头中试摆：母版定义的结构、身份特征、表面、单位尺度和光向是否漂移；交互对象是否滑脱、穿透或重复。局部编辑后仍交付完整姿态，不把角色部件拆出装配。

逐张核对本项目不变量、状态变化依据、资源占用、支撑及过程覆盖。未经依据的几何／状态漂移、超出已建立能力的动作、缺失必要因果或交接均标 rejected；不能以美观或文件格式通过代替动作验收。

同一问题连续两次修正无改善时，先诊断参考、角度或工具限制，改用更简单动作、组合图或局部修整；未获用户同意不要主动增加付费额度。已有完整制作授权内继续其他不受影响任务，记录限制。

完成后交付实际素材、资产索引、镜头覆盖情况与缺口。只存在提示词的项仍是 planned；检查通过的素材才能作为正式镜头依赖。转入 [animate](../stopmotion-animate/SKILL.md)。
