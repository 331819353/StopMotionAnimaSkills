# 定格故事与剧本

先读 [定格语言](../stopmotion-production/references/stopmotion-language.md) 和 [交接规范](../stopmotion-production/references/project-contract.md)。从已有简报和资产约束起步，不重复询问已有信息。独立使用时补充必要简报，并明确合理假设。

## 故事设计

1. 确定受众、片长、角色目标、性格缺陷／优势、阻力与选择后果。把“大众审美”落到易读动机、可感知情绪、可辨认冲突、清楚回收，不承诺人人喜欢。
2. 先找能摆放的故事载体：一个会被误认的物件、一组会升级的堆叠、藏在前景的线索、一项有代价的替换。让关键事件由可见动作造成，避免大量画外叙述、复杂追逐、无意义换景或只靠台词解释反转。
3. 列节拍：建立目标与空间 → 尝试与后果 → 升级 → 关键选择／揭晓 → 反应与回扣。按题材调整，不强迫所有片子套固定段数。
4. 将节拍写成定格事件：谁／哪个道具，从什么状态，经哪些关键姿态，变到什么状态；标出停格、视线和反应让信息被看见。
5. 检查每个新增角色、角度、场景、破坏状态与接触动作的资产成本。形态改变按项目模式需要整画面动作帧或完整角色姿态；不能假设可拆角色部件能覆盖所有事件。先优化表达，不因为生成方便而塞入不必要的动作。

写节拍时按 [连续性与物理规范](../stopmotion-production/references/continuity-and-physics.md) 检查实体尺度、状态继承、操作资源与动作依赖。根据角色能力、负载和空间条件安排事件顺序，不预设固定操作方式。笑点涉及特殊世界规则时提前建立；不能靠未解释的尺寸、状态或位置突变解决因果缺口。

整画面模式按 [阶段母版与整画面替换](../stopmotion-production/references/full-frame-workflow.md) 估算大幅位移和复杂交接风险，必要时分阶段设计镜头；不能通过切镜跳过关键因果或已要求的中间过程。

## 幽默与反转

- 视觉笑点优先来自预期落差、重复升级、物件比例／归属误判、角色反应；决定笑点的停格要写入剧本，不只写“搞笑地”。
- 反转写成“先前可见线索 → 观众合理误读 → 新信息 → 旧画面获得新含义”。给线索对应镜头和实体资产，回查不能靠剪掉必要信息作弊。
- 幽默强度随受众与题材调整；严肃题材不要机械插笑点。人物愚蠢不是唯一幽默来源。

## 时间结构

用户偏好多时间线交叉时优先尝试，但先保证可理解性。分别维护事件发生顺序、影片播放顺序、观众知识状态。区分不同时间段的交叉与同一时刻不同人物的平行剪辑。

用同一实体道具的不同状态、布景部件替换、固定构图的状态匹配等定格方法标识时间；辅以必要的色彩或文字，不能只靠细微滤镜。每次切换必须有信息增量或因果作用。

片长或资产预算装不下多线时，先提出“现在行动＋过去关键片段”等可行简化；不得默默取消用户明确要求。用户坚持多线则压缩人物、场景或其他支线，并说明权衡。

## 故事化科普

进入 hybrid 前，先读 [stopmotion-explainer](../stopmotion-explainer/SKILL.md) 建立已核实的论断与模型边界。人物应通过操作、观察、比较或纠错经历机制，而非停下剧情背知识。

允许观众／人物先误解，最终必须纠正；不让角色意愿改变物理规律，不为反转篡改科学条件。拟人的意图与实际因果分开表述。每个知识事件标 claim_id，交回 explainer 核查。

## 输出与自查

保存梗概、角色与实体道具表、节拍剧本、反转线索表、时间结构表（适用时）、粗略素材负担。节拍字段按交接规范，特别写清可见变化与起止状态。

检查：主角行动是否造成后果；不听对白能否辨认核心物件变化；笑点和揭晓是否有阅读时间；每条时间线是否容易分辨；是否存在无铺垫道具、无法通过素材摆放实现的动作或超预算姿态。修复后交给 [分镜](../stopmotion-storyboard/SKILL.md)，不把文字剧本标为已生成动画。
