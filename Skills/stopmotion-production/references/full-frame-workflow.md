# 整画面定格：阶段母版与目标状态

用于用户选择不拆场景拼装的制作方式，或分层交接成为主要误差来源时的整画面小样。一个素材是一张完整镜头画面，通过离散替换和停格播放；不等于独立重画每个输出帧，也不等于视频生成。作品设定和实验数据保存在项目内。

## 制作方式与参考分工

用户已指定整画面时直接采用，不为复用或节省素材擅自改回拼装。未指定时，按接触复杂度、机位、精确性和已有小样选择；整画面与整角色分层各有误差来源，不能宣布其中一种普遍最稳。需要精确分件的知识模型另按科学表达要求处理。

- 角色形态参考／三视图：外形、结构、服装、材质和身份。不是可拆部件，也不能单独定义场景中的比例、机位与状态。
- 场景母版：固定画幅、机位、构图、实体几何、光向和静态环境；先核对项目尺度与接触空间，风格通过不足以升为生产母版。
- 阶段母版：某个事件时间与动作阶段的完整已验收快照，继承场景几何及当时的物品状态。状态变更必须有事件依据。
- 前帧：动作接续、接触路径、遮挡和状态的比较依据。是否作为生图输入需要测试，不默认无限沿前帧串行编辑。

## 先比较，再选参考策略

在同一镜头选代表姿态，按需要比较母版直接派生、前帧串行编辑、母版加前帧。多参考不自动更稳；明确每张图的职责和冲突优先级，防止旧母版把当前状态重置。小样同时判断目标动作是否实现，不能只选背景最相似的静帧。

静态内容与身份发生累计漂移时，优先试从固定阶段母版直接生成各目标状态，前帧用于验收；复杂接触确需前帧输入时限定其作用范围。策略及其证据、样本量与未覆盖情形留在项目，不把单次表现当作跨项目保证。

## 整画面生成

每次调用读 [提示词分层与绑定](prompt-contract.md) 和 [连续性规范](continuity-and-physics.md)。写明：

1. 本镜头／阶段母版与参考职责，固定画幅、机位和光照。
2. 目标瞬间、允许改变的实体／区域／关系，以及明确不变项。
3. 当前进入状态、事件及目标状态。母版较早时显式覆盖过时状态，不让工具猜剧情历史。
4. 完整角色、交互、遮挡、支撑与资源占用；同时约束未参与动作的实体、环境痕迹和内容物。
5. 输出一张完整画面，不输出透明角色切片、拼装部件、多格分镜或多重姿态。

同一输出帧可保持多帧，只有可见姿态／状态变化才新增画面。通过整图编辑修复；不把角色／道具局部缩放、搬移或背景拼贴作为隐藏生成错误的办法。全片统一的交付尺寸转换另行记录，不改变局部实体比例。

## 阶段划分与失败处理

优先把微动作做成有限、可读的离散状态。大幅位移、转向、多物交接会增加漂移风险；按动作依赖分阶段或设计必要的切镜，每个新镜头重建合法机位下的母版。切镜不能省掉用户要求、科学机制或关键支撑交接；改变机位也不能掩饰无依据缩放。

阶段切换先核对旧阶段退出状态与新阶段进入状态。只有相应身份、几何、状态、接触和静态内容检查通过的帧才能成为生产母版。失败帧可在明确标注的诊断分支中研究，不能混入正式依赖或因派生结果好看而倒改为通过。

同一问题两次定向修复无改善时停止沿该分支扩量，检查参考冲突、动作幅度、构图或工具能力。在当前授权内改用更易验证的镜头／阶段设计；缺乏可行输出时交付失败证据与限制，不承诺提示词能硬锁像素。

## 验收与整帧播放

逐项检查目标动作、身份与结构、相对几何、物品状态、接触／支撑、未授权的实体移动／新增痕迹，以及背景纹理与光照闪烁。若测试跟随或其他机位变化，所有固定地标需服从同一相机变换；主体屏幕大小稳定不足以证明空间成立。遮挡解除时核对原对象重新显露，不能重画成重复对象。

固定机位可在已声明静态区域测量像素差或地标偏移；记录坐标、尺寸处理、方法和阈值来源。纹理差不等于几何错误，低像素差也不证明动作、物理或知识成立。比较小样不等于重复统计试验，不宣称全局最优。

完整画面用同一全画布轨道按整数帧替换，通常固定位置、尺度、旋转与不透明度；不对角色和道具分别重定位，不添加插帧或平滑变形。查看正常播放和关键帧，区分静态关键图、关键姿态停格预览、完整动作与成片四种完成程度。未通过的诊断预览显著标识，禁止当量产完成品交付。
