# 定格语言：所有阶段共用

## 让定格成为表达方法

每段内容都安排可辨认的离散状态：摆出预备姿态，按设计步长移动或替换，停住让观众读懂，再进入反应。运动轨迹可以预先计算，但渲染结果只能在指定帧切换或移动。不要默认输出连续补间后加“卡顿滤镜”。

场景像可摆放的微型舞台：地面、支点、出入口、前后层级、接触位置明确。根据镜头选择合适材质；不把写实摄影画面简单减帧当作本流程成果。脚印、边缘厚度、可控接触阴影、材质纹理都应稳定；闪烁、轮廓漂移和落脚点乱跳不是“手工感”。

## 剧作必须能摆出来

- 用道具的形态、位置、归属或状态表达信息。例如物件被逐次藏起、替换、拆解、排队、堆叠，既可产生笑点，也可解释机制。
- 视觉幽默按“建立预期 → 停格 → 可见偏差 → 反应姿态 → 回扣”安排；不要求每段都有笑点，不用旁白替代关键视觉事件。
- 反转让同一个道具、摆位或动作获得新含义；线索此前应可见，不能临时生成一个无铺垫的新物件解决问题。
- 科普用可追踪的部件移动、切面替换、对照摆放、计数或层层显露来展示因果。装饰性的角色走动不等于解释。
- 镜头语言优先服务素材复用与理解：固定机位、明确方向和可读构图常有利于制作，但不禁止必要的切镜或离散机位移动。换角度需要对应资产，不能靠平面图强行旋转出立体侧面。

## 动作设计

每个动作先写五项：目的、承重／接触点、关键姿态、间隔与停格、结束接续状态。按动作需要加入预备、突破、跟随和回稳；不强迫所有动作使用同一模板或帧数。

区分：

1. 平移／旋转：分层时复用相同图层，旋转只适用于所选平面和材质；整画面时生成对应目标位置的完整帧。
2. 形态改变：替换姿态，如迈步、张嘴、压扁、液面改变。
3. 交互：整画面在完整镜头中解决；分层生成完整角色与交互对象的一体姿态，图内固定接触、支撑和遮挡关系；交互持续期间整体替换该组合。实体从独立层转入组合时需互斥交接，不能重复显示。
4. 拆解／剖面：用预先设计的分件及切面序列，保持对应关系。
5. 相机变化：以离散状态整体改变布景与前后层，或生成新角度；不能假装一个平面拥有未生成的背面。

整画面可按 [阶段母版](full-frame-workflow.md) 生成有限姿态帧再停格播放，分层可替换与摆放素材；两者都不能以连续视频生成或卡顿滤镜替代定格设计。

动作不是换图越多越好。停住、视线、构图和音效可能比新增姿态更有效。静止的背景与道具无需动作套图。

角色动作使用完整姿态替换，结构以母版为准，不拆角色身体、附肢、操作部位或表情组件装配。前景环境可分层，科普模型可分件；不能借此改回分件角色。每个姿态以同母版、画布、视角、单位尺度和相应承重点派生；身份特征与交互对象局部坐标需逐姿态检查。按具体姿态记录实际支撑关系，不能一律按外接框中心对齐。

## 定格科普的准确性

抽象机制被实体化后可能引入不存在的“碰撞”“意图”“大小关系”。为每个模型写清：画面中的部件代表什么，哪种关系可靠，哪些尺度、速度、数量、颜色被简化。拟人角色可以作引导，但不可替代科学因果。

不按比例、加速演示、示意模型等提示，在可能误导的镜头附近可读地呈现；不要只藏在片尾。精确文字、箭头、数字、公式与图表用排版／绘图生成再合成。它们也是离散摆放的资产，不要求由普通生图产生错误文字。

## 通用检查

- 关闭旁白后，核心动作或因果是否仍可辨认？需要旁白解释的概念不强求完全无声独立成立。
- 连续播放与逐帧查看都检查：脚底／支点、接触、轮廓、光向、层级、换姿瞬间和镜头进出状态。
- 对话不默认写实唇形同步，可用整人物表情姿态、身体反应、字幕或画外音；不为嘴型另拆角色组件。
- 不默认添加随机抖动；需要手摆微差时，限定在不会改变身份、接触和知识含义的范围内。
