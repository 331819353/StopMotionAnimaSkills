# 定格动画制作总入口

## 创作与实现约定

本套流程面向 AI 生图驱动的替换式数字定格：生成完整画面或完整角色素材，用离散姿态替换、摆放与停格产生运动。纸偶、黏土、毛毡、积木、微缩模型等是可选材质，不强制统一为纸剪风格。

先阅读 [定格语言](references/stopmotion-language.md) 和 [项目交接规范](references/project-contract.md)。这些约束同时适用于故事、科普和混合模式。不要把通用剧本、普通运动图形或图生视频流程换一个“定格”名称交付。

动作生图前执行 [尺度、状态、物理与过程连续性](references/continuity-and-physics.md)：锁定实体几何与机位，维护逐阶段状态，检查操作能力、负载、资源占用、必要中间过程及人物／相机各自可见的表面。信息展示服从真实朝向，观众需要读取隐藏内容时另设合法切镜或说明层。按 [提示词分层与绑定](references/prompt-contract.md) 将通用规则绑定到当前项目；demo 只用于验证，不向技能注入角色、道具、数值、材质或固定动作方案。

- 用户选择整画面时，按 [阶段母版与整画面替换](references/full-frame-workflow.md) 制作完整镜头帧，不拆人物、道具和背景拼装。没有指定方式时按代表动作小样选择；不得把整画面编辑等同于每帧脱离参考重新绘制，也不默认分层一定更稳定。
- 角色以完整动作姿态为最小生产单元：结构以当前角色母版为准，表情随整姿态生成；不拆身体、附肢、操作部位或表情组件进行角色装配。此约定适用于不同角色结构，不预设人类四肢。多视角参考板不能代替独立的完整姿态。
- 交互在生成图内部解决接触、支撑与遮挡。整画面模式保留完整场景；分层模式使用完整角色与交互组合，独立管理环境。两种模式都需验证跨姿态稳定性，不能自行切换已指定的方法。
- 不用视频生成、光流补帧、连续骨骼变形或默认平滑插值替代核心定格动作。文字排版、蒙版、抠图、声音处理和渲染可采用确定性工具。
- 每个情节或知识点都要落到“哪些实体素材，以哪些姿态、摆放位置和停格时长，发生什么可见变化”。
- 用户要求文字策划时只交付策划；授权完整制作时继续到可实现的成片阶段。不得将缺少生图／渲染工具的计划声称为成片。

## 解析要求与选择模式

读取用户现有要求和已有产物。只追问会影响制作或事实正确性且无法合理推断的信息；其余写入制作简报的 assumptions。

简报至少识别：受众、主题、模式、目标时长、比例与分辨率、发布场景、对白语言、材质风格、可用参考、预算／素材上限、交付范围。未指定模式时：主要目标是人物命运用 story，理解知识用 explainer，以故事推动知识理解用 hybrid。明示推断。

帧率与动作更新率分别记录；初始可用 24 fps 输出、以每 2–3 帧换姿为试验起点，不作为所有影片的固定规则。短片和复杂接触动作先做一个代表镜头测试，再估算姿态成本。

## 路由与顺序

这些技能是同目录下的配套技能。按实际阶段读取，不一次加载全部。

| 阶段 | 读取技能 | 输出与推进条件 |
|---|---|---|
| 故事型 | [stopmotion-story](../stopmotion-story/SKILL.md) | 故事因果、时间线、视觉笑点、可制作事件 |
| 科普型 | [stopmotion-explainer](../stopmotion-explainer/SKILL.md) | 核心问题、来源与论断表、实体机制演示 |
| 故事化科普 | 先 explainer 的知识边界，再 story，再回查 explainer | 故事行为和知识机制共同成立；科学事实不能为反转让步 |
| 基础视觉测试 | [stopmotion-assets](../stopmotion-assets/SKILL.md) 的“前期小样” | 少量母版与材质样张，不提前批量生图 |
| 分镜与动态分镜 | [stopmotion-storyboard](../stopmotion-storyboard/SKILL.md) | 镜头、帧数、姿态草图和临时声音验证可读性 |
| 正式素材 | [stopmotion-assets](../stopmotion-assets/SKILL.md) | 锁定母版与参考，整画面动作帧或完整角色／交互素材 |
| 逐镜动画 | [stopmotion-animate](../stopmotion-animate/SKILL.md) | 帧表、合成时间轴、可播放镜头 |
| 成片 | [stopmotion-finish](../stopmotion-finish/SKILL.md) | 剪辑、声音、字幕、模式相关检查与交付 |

“推进条件”是内部质量检查，不是强制每阶段向用户索要确认。尊重已有授权；用户要求审稿或关键约束无法确定时才暂停相应依赖，继续独立工作。

## 项目状态与返工

在用户指定项目目录保存产物；未指定时，在当前工作区建立专用项目目录，不把影片素材写入已安装的 skill 目录。使用固定 ID 连接剧本节拍、论断、镜头、资产、姿态、声音和版本，见交接规范。

开工先检查现存项目，复用已核实且未失效的产物。每次变更记录原因和影响：剧本结构改变回查镜头；角色外观改变只失效受影响姿态与镜头；对白改变检查帧数和口型；论断改变回查讲解、标注和示意素材。不要无理由全量重生。

成本按实际模式的“新母版＋新角度＋整画面姿态或完整角色／交互组合＋返修”估算，单列输出帧数，不能按帧数冒充生图次数。预算不足时优先复用整姿态、改变构图或简化动作，不自行降级为分离肢体拼装，并说明对叙事／知识表达的影响。

## 工具与完成边界

生图时发现并使用当前可用的图像生成／编辑工具，读取其适用 skill；保存真实返回的文件与参考关系，不编造图像链接、工具能力、随机种子或版本。优先基于已选母版编辑派生；工具不支持所需一致性时先试样并报告限制。

对白／旁白使用 [Fish Audio MCP](../stopmotion-finish/references/fish-audio.md)，从配套音色表按角色年龄、性别与表演需求选声并固定角色映射。简报阶段识别配音需求，分镜阶段按需用代表台词实测节奏；正式音频可用后再锁定相关镜头计时。只做策划时不生成声音，缺工具时明确缺口。

无工具时完成能做的脚本、镜头、姿态清单和提示词，并明确哪些是计划、哪些是实际生成。基础合成可使用 animate 自带脚本；复杂遮挡、灯光、接触或声音使用实际可用的合成工具完成，保持离散帧规则。

结束时说明：已完成阶段、交付位置、核验范围、仍缺的真实素材或工具；不把“已写好提示词”标记成“已生成素材”。
