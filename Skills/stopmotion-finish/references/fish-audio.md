# Fish Audio MCP 配音

本套技能的对白与旁白采用 Fish Audio，经 MCP 调用；不擅自换用其他 TTS 或绕过 MCP 直连开发者 API。音效与音乐另按实际来源管理。只做文字策划时记录配音设计，不生成音频。

## 连接与能力检查

服务地址为 `https://api.fish.audio/mcp`，使用 Streamable HTTP 和浏览器 OAuth。按 [Fish Audio 官方连接文档](https://docs.fish.audio/overview/mcp) 和 [Codex MCP 文档](https://learn.chatgpt.com/docs/extend/mcp) 配置：

```sh
codex mcp add fish-audio --url https://api.fish.audio/mcp
codex mcp login fish-audio
codex mcp get fish-audio
```

已有同名配置时先核对，不重复添加或覆盖；添加时已成功登录则无需重复登录。连接配置不等于 OAuth 已完成，OAuth 完成也不等于当前聊天已加载工具。未出现工具时重新连接／刷新客户端，再发现实际工具及参数。凭据由客户端管理，不写入仓库或影片项目。

官方 [工具说明](https://docs.fish.audio/overview/mcp/tools) 列有 `get_voice`、`text_to_speech` 与 `get_credit_balance`；调用前以当前服务器返回的 schema 为准，不猜测参数名。实际生成会消耗账户额度，按当前费用与项目预算执行；本参考不固定费率。缺连接、权限或额度时继续独立工作并记录阻塞，不冒充已生成，也不自动改用服务默认音色。

## 选声与角色绑定

从 [用户指定音色表](fish-audio-voices.json) 选择。该表保留用户给出的原始 ID 与性别／年龄分组；分类不等于已验证的音色属性或服务端可用性。

1. 在简报／剧本阶段明确角色与旁白的声音需求；按角色的性别、年龄段和表演气质选择对应组，不按观众年龄给所有角色配同类声音。旁白按作品需要选组，缺省选择作为项目假设记录。
2. 已指定具体 ID 时优先验证它；只指定分组时可按表中顺序核对元数据与已有样音，选出合适候选，再按需用少量代表台词测试，不批量为所有候选生成付费试听。需要区分的角色优先选择不同音色。
3. 用 `get_voice` 或当前等效工具核实 ID、可访问性、语言与已有样音；实际听感需监听后才能声明通过。ID 不可用时记录服务端结果，未锁定的候选可换同组其他有效 ID；已锁定的角色需要换声时说明原因并更新角色映射及受影响音轨，不静默更换。
4. 同一角色在全片固定 `speaker_id → voice_id`；情绪与语气通过当前工具支持的参数／文本标签表达。标签仅传给配音，不作为台词或字幕朗读显示；数字、单位与多音字的朗读处理保留与原稿的映射。

原始表含 54 个互不重复的候选 ID，均为 32 位十六进制形式；形式符合不代表服务端可访问或听感合适。不得自行补零、截断或猜测修复 ID；验证结果与替换依据留在影片项目。

## 生成、落盘与时间轴

以说话人和可独立返修的语义段拆分台词，引用稳定的 `AUD_*` ID、剧本版本与镜头。调用 `text_to_speech` 时显式传入已选音色，参数按实际 schema 填写；保持语言与有效模型／设置一致。保存真实调用、结果链接及本地文件；返回多个片段时逐一登记并保留顺序。请求结果不确定时先查已有结果，避免盲目重复生成。

文件保存在影片项目的 `audio/` 下；核验文件可解码并实测时长。记录说话人、音色 ID、文本／标签、工具与可得设置、来源、实际时长、采样率、声道、版本和检查状态；不把工具未返回的数据编造为已知。无权访问或无法保存的结果明确标缺口。

分镜可用少量真实配音校准节奏；正式配音可用后，按实测时长对齐镜头与字幕。覆盖音轨所需帧数向上取整：`ceil(duration_seconds × fps)`；句内字幕／动作 cue 按实际音频定位，不能仅按字数均分。该时长不等于整个镜头时长，预备、反应与停格另计。时间不足时改稿、调整 hold 或重排镜头；不默认加速配音或补帧。基础 PNG 合成脚本不混音，使用实际编码／剪辑工具加入音轨。

文本、音色或影响听感的设置改变时只重生受影响段落，复用未变化且已检查的音频。最终监听漏字、重复、发音、说话人一致性、语气、截断、爆音及音乐遮盖，回查字幕和整数帧同步。无法监听时记录未验证范围，不把文件存在当作听感验收。
